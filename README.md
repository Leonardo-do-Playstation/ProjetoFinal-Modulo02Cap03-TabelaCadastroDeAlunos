📚 Cadastro de Alunos em Tabela

Aplicação web simples que permite cadastrar alunos e exibir os dados em uma tabela dinâmica, utilizando HTML, CSS e JavaScript.

O projeto foi desenvolvido com o objetivo de praticar manipulação de formulários, manipulação de DOM e atualização dinâmica de tabelas no frontend.

🚀 Tecnologias Utilizadas

HTML5

CSS3

JavaScript

📌 Funcionalidades

✔ Cadastro de alunos através de formulário
✔ Exibição dos alunos em uma tabela
✔ Atualização dinâmica da tabela após o cadastro
✔ Manipulação de dados diretamente no navegador

⚙️ Como Executar o Projeto

1️⃣ Clone o repositório

git clone https://github.com/Leonardo-do-Playstation/ProjetoFinal-Modulo02Cap03-TabelaCadastroDeAlunos.git

2️⃣ Entre na pasta do projeto

cd ProjetoFinal-Modulo02Cap03-TabelaCadastroDeAlunos

3️⃣ Abra o arquivo index.html no navegador

Ou utilize uma extensão como Live Server no VS Code.

🧠 Como Funciona

O usuário preenche os dados do aluno no formulário

Ao clicar no botão de cadastro, o JavaScript captura os dados

Os dados são adicionados dinamicamente à tabela

A tabela é atualizada na tela sem recarregar a página
